# Fonts

Generated LVGL fonts, copied unchanged from the UNA SDK (2026-11-27), where
`Utilities/Scripts/lvgl_assets/lvgl_assets.py` produced them from Poppins
(SIL Open Font License 1.1) with lv_font_conv, 2 bpp, uncompressed:

| File | From | Glyphs |
|---|---|---|
| `poppins_semibold_60.c` | `Examples/Apps/RunLVGL` | space to `:` (digits, `.`, `%`), `A M O P e n p` |
| `poppins_medium_25.c` | `Docs/Tutorials/Files` | printable ASCII |
| `poppins_regular_18.c` | `Docs/Tutorials/HelloWorld` | printable ASCII |

The 60 px face prints numbers only; anything with letters uses the others.
